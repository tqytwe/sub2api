## Baseline

账号端点能力使用既有复选框。分组模型定价包含图片输入和输出 token 单价。

## Prototype

新增默认关闭的视频中转选项。OpenAI 分组按 token 计价可配置每张图的最低收费。

## Reuse Decision

沿用账号弹窗和 PricingEntryCard。

## State Coverage

图片金额支持空值和配置值，既有表单处理保存中和保存错误。

## Viewport Coverage

审查板渲染 360px 和 1280px。

## Evidence

审查板 PNG 见清单。

## Scope

账号端点选择和 OpenAI 分组的图片价格输入。

## Residual Risk

上线后需在实际管理员表单检查中英文、保存错误、回读及主题切换。

CSV 导出沿用原按钮和提示状态。导出请求改用较大的分页并在限流后继续，页面布局保持一致。

兼容性审查板补充 New API 授权预览、API Key 分组选择宽度和 Pelican 交互预览。
定向测试覆盖金额币种、下拉宽度约束，以及只有交互预览获得指针锁定。
静态审查板不代表运行时页面截图或生产验收。
