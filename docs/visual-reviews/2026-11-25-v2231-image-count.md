## Scope

OpenAI 和 Composite 分组启用生图后显示一项计费配置。编辑弹窗从分组 API 回读，创建弹窗默认关闭。

## Baseline

`baseline-1280.png` 捕获 #457 候选构建的分组编辑弹窗与图片生成计费区。

## Prototype

`prototype.png` 是改动前保存的设计图。新增复选框与解释位于生图启用选项和价格字段之间。

## Reuse Decision

沿用现有分组弹窗、复选框、计费表单布局、主题和提交接口。

## State Coverage

Chromium 验证已开启的值、键盘切换、提交及重开回读。组件测试验证关闭生图时隐藏选项、提交 `false`。加载、保存失败和成功通知沿用现有表单行为。区域无独立加载、空状态或动画。

## Viewport Coverage

在 360、768、1280、1920 像素视口验证新增区块的滚动可达性、字段操作和横向边界。覆盖中英文、浅色和深色。

## Evidence

修改前后的画面均来自构建后的管理路由，通过浏览器网络拦截载入隔离测试数据。原型为静态设计图。

## Residual Risk

生产数据库持久化和实际账户验收需要发布后核对。
