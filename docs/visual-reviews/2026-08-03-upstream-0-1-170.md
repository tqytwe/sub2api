- Roles: guest, ordinary user and administrator.
- Languages and themes: Chinese and English in both supported themes.

- Current behavior: `origin/play/main` before importing upstream `v0.1.169` and `v0.1.170`.
- Baseline screenshot or recording: `assets/upstream-0-1-170/baseline-static-review-board.png` records the protected fork surface inventory.

## Reuse Decision

- Shared layouts and components reused: route frame, native buttons, existing Toggle semantics, payment selector, Model Plaza tables, admin forms and localized copy structure.
- New shared pattern, if any: no new component family; compact home uses the shared route frame instead of setting its own viewport size or width.
- Design-system exception, if any: none in the imported visible controls.

## State Coverage

- Default: public compact home, account billing controls, Model Plaza pricing, subscription quotas and group profit controls retain their existing information hierarchy.
- Hover and active: payment selection transitions only colors; account and group actions reuse the existing controls.
- Focus-visible and keyboard: new namespace toggles use `focus-visible` rings and remain native buttons.
- Loading, disabled, empty, error and success: disabled payment methods, probe failures, quota empty states and admin validation remain rendered by the existing state components.

## Viewport Coverage

- Mobile: 360x800 review targets the compact home, wrapped payment grid and narrow administrator form controls.
- Tablet: responsive form rows and Model Plaza filters retain their wrapping behavior.
- Desktop: 1280x800 review targets dense group, account and subscription administration.
- Wide or short screen: compact public home now delegates viewport and width ownership to the shared frame.
- 200% zoom and reduced motion: no added continuous motion; visible controls use bounded dimensions and wrapping text.
