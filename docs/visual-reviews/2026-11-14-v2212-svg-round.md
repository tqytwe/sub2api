## Scope

This cumulative worktree starts at deployed `2a457bedf0e4bfb867342a18d1c41645bb834a46` and ports the fixed `v2.21.2@dbed7697aa56e76c6eb48c4914fa441496b67bdd` question bank. It reuses the prior unfinished candidate’s reviewed prototype; updated evidence renders the current actual components, with synthetic API/artwork explicitly identified. The change connects four fixed SVG drawing questions to existing administrator and user surfaces. It adds no user route. Administrators select custom or random mode in group and account schedules, may prepare a shared manual round before an account test, and can inspect the saved question with its result. Users reach the question and criteria from the existing V2 channel-card history for a configured public group.

## Baseline

The existing Pelican administrator screen and channel-history dialog already provide group schedules, result history, and a large sandboxed artwork preview. Those real captures are retained as the baseline. Before this change, the SVG prompt was custom-only in the scheduled editor, and published artwork history carried no immutable question snapshot.

## Prototype

`assets/svg-question-bank-20261114/prototype.png` was made before implementation from the existing administrator page and dialog. It shows the intended locations for the mode selector, round preparation, question snapshot, and channel-history result. The change remains within those existing surfaces.

## Reuse Decision

The implementation reuses existing account and group test dialogs, `Select`, `TextArea`, the V2 group-card history entry, `PelicanArtworkPreview`, and the existing result APIs. The shared `PelicanQuestionSnapshot` contains only question identity, prompt, round identity, and visual review criteria. It does not expose account identity or internal transport diagnostics to users.
