原型设计 - P0-3: 盲盒奖励分支说明

奖励类型

开盒后可能获得余额、优惠券或兑换码之一：

优惠券
60%
兑换码
20%
余额
20%
优惠券：可用于抵扣充值金额
兑换码：可兑换指定额度
余额：直接到账
📊 权重数据来源：

从 API /play/blindbox/status 获取：

  • coupon_weight_bp = 6000 (60%)
  • redeem_code_weight_bp = 2000 (20%)
  • balance_weight_bp = 2000 (20%)

⚠️ 权重单位为 basis points (bp)，10000 = 100%

📱 移动端适配：
  • 标签宽度在小屏幕下缩小为 60px
  • 百分比条自动适应剩余宽度
  • 图例在窄屏下自动换行
  • 最小宽度 360px 不溢出
🌙 深色模式：
  • 卡片背景：#581c87（紫色深色）
  • 卡片边框：#7c3aed
  • 标签文字：#d1d5db
  • 条形背景：#374151
  • 渐变保持原色系，亮度降低
💡 交互行为：

权重数据动态从 API 加载，每次打开盲盒页面时刷新。如果 API 未返回权重字段，使用默认值（50% 优惠券，30% 兑换码，20% 余额）。
