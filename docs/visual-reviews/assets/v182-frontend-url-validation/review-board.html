Before

Boundary

Canonical base URL is required

Allowed: an empty value or absolute HTTP(S) base URL. Rejected: queries, fragments, userinfo, and non-HTTP(S) schemes. The server remains the final enforcement point.

After

Input stays visible and submission stops

Use an absolute HTTP(S) base URL without a query, fragment, or user information.

Outcome: the value is preserved for correction. No update request is issued and no setting is cleared.
