每项先真实 HTTP RED，再最小修复；概率、未知结果与事务缺陷另由真实 PostgreSQL/HTTP/Vue 验证。后端生产修改仅 `play_handler_extended.go` 的 DTO 投影，`api/play.ts` 仅补可选字段。未改资格、奖种、成本、价格、计费、路由、SQL275/276 或 P0 台账实现。
