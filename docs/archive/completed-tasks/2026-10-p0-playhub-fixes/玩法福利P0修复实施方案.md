## 二、P0-1：补充邀请活动详情展示

### 2.1 问题描述
**文件**：`frontend/src/views/user/AffiliateView.vue`  
**当前状况**：用户只能看到活动名称和"关注"徽章，不知道：
- 阶梯奖励档位（充满¥50得¥50，满¥200再得¥50...）
- 达标条件（净实付 + 实际消费双门槛）
- 风控冻结时长（奖励冻结X小时）
- 领取截止时间

**影响**：用户频繁询问客服，或因不了解规则而错失奖励

### 2.2 数据来源确认

根据 `frontend/src/api/referralCampaign.ts`，API 已返回完整数据：

```typescript
export interface ReferralCampaignProgress {
  campaign: {
    name: string                           // 活动名称
    pay_threshold: number                  // 净实付门槛
    usage_threshold: number                // 实际消费门槛
    risk_hold_hours: number               // 风控冻结时长
    claim_deadline: string                // 领取截止时间
    reward_mode: 'additive' | 'replace'   // 奖励模式
    public_rules_md: string               // 公开规则（markdown）
    legacy_rebate_policy: 'exclude' | 'stack' // 与常规返佣的关系
  }
  progress: {
    net_payment_cny: number               // 当前净实付
    consumption_cny: number               // 当前实际消费
    qualified: boolean                    // 是否达标
    reward_tiers: Array<{                 // 阶梯奖励
      tier: number
      threshold_cny: number
      amount_cny: number
      reached: boolean
    }>
  }
  rewards: ReferralCampaignReward[]       // 已获得的奖励
}
```

#### 计算逻辑（在 `<script setup>` 中添加）

```typescript
const couponPercentage = computed(() => {
  if (!status.value) return 0
  return Math.round((status.value.coupon_weight_bp / 10000) * 100)
})

const redeemPercentage = computed(() => {
  if (!status.value) return 0
  return Math.round((status.value.redeem_code_weight_bp / 10000) * 100)
})

const balancePercentage = computed(() => {
  if (!status.value) return 0
  return Math.round((status.value.balance_weight_bp / 10000) * 100)
})
```

| i18n 缺失导致显示键名 | 用户体验差 | 低 | 补充英文翻译，测试语言切换 |
| 原型图片缺失导致无法实施 | 阻塞开发 | 高 | 协商使用文字规范直接实施 |
