# P0-3: 盲盒奖励分支说明 - 修改指南

> 生成时间：2026-10-06  
> 任务：在 BlindboxView.vue 补充三路奖励分支说明

## 📋 问题描述

**当前问题**：用户只看到"余额奖励"提示，不知道盲盒还有优惠券和兑换码两个分支。

**目标**：明确告知用户盲盒可能开出三种奖励之一，并显示当前权重分配。

---

## 🎯 修改内容

### 1. 添加国际化键值

在 `frontend/src/i18n/locales/zh-CN/dashboard.ts` 的 `play.blindbox` 对象末尾添加：

```typescript
rewardBranches: {
  title: '奖励类型',
  description: '开盒后将随机获得以下奖励之一：',
  coupon: '优惠券',
  redeemCode: '兑换码',
  balance: '余额',
  probability: '概率 {percent}%',
  note: '具体奖励金额/折扣根据当前奖池配置随机生成'
}
```

在 `frontend/src/i18n/locales/en/dashboard.ts` 添加对应英文翻译。

### 2. 修改 BlindboxView.vue

在盲盒开启按钮上方添加奖励分支说明卡片，展示三路权重分配。

---

## 📝 代码示例

在 BlindboxView.vue template 中的开盒按钮上方插入：

```vue
<!-- Reward Branches Explanation -->
<div class="mb-4 rounded-lg border bg-blue-50 p-4 dark:bg-blue-900/10">
  <h4 class="text-sm font-semibold text-blue-900 dark:text-blue-200">
    {{ t('play.blindbox.rewardBranches.title') }}
  </h4>
  <p class="mt-2 text-xs text-blue-800 dark:text-blue-300">
    {{ t('play.blindbox.rewardBranches.description') }}
  </p>
  
  <div class="mt-3 grid gap-2 sm:grid-cols-3">
    <div class="rounded bg-white p-3 dark:bg-dark-800">
      <p class="text-xs font-medium text-gray-900 dark:text-gray-100">
        {{ t('play.blindbox.rewardBranches.coupon') }}
      </p>
      <p class="mt-1 text-sm font-semibold text-purple-600 dark:text-purple-400">
        {{ t('play.blindbox.rewardBranches.probability', { 
          percent: ((poolConfig?.coupon_weight_bp || 0) / 100).toFixed(1) 
        }) }}
      </p>
    </div>
    
    <div class="rounded bg-white p-3 dark:bg-dark-800">
      <p class="text-xs font-medium text-gray-900 dark:text-gray-100">
        {{ t('play.blindbox.rewardBranches.redeemCode') }}
      </p>
      <p class="mt-1 text-sm font-semibold text-orange-600 dark:text-orange-400">
        {{ t('play.blindbox.rewardBranches.probability', { 
          percent: ((poolConfig?.redeem_code_weight_bp || 0) / 100).toFixed(1) 
        }) }}
      </p>
    </div>
    
    <div class="rounded bg-white p-3 dark:bg-dark-800">
      <p class="text-xs font-medium text-gray-900 dark:text-gray-100">
        {{ t('play.blindbox.rewardBranches.balance') }}
      </p>
      <p class="mt-1 text-sm font-semibold text-green-600 dark:text-green-400">
        {{ t('play.blindbox.rewardBranches.probability', { 
          percent: ((poolConfig?.balance_weight_bp || 0) / 100).toFixed(1) 
        }) }}
      </p>
    </div>
  </div>
  
  <p class="mt-3 text-xs text-blue-700 dark:text-blue-400">
    {{ t('play.blindbox.rewardBranches.note') }}
  </p>
</div>
```

**数据来源**：
- `poolConfig` 来自 API 返回的盲盒奖池配置
- 包含 `coupon_weight_bp`, `redeem_code_weight_bp`, `balance_weight_bp` 三个字段
- BP（Basis Point）= 万分之一，除以 100 得到百分比
