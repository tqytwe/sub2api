## 交付与使用

1. 用户在签到页正常签到。里程碑按用户、签到业务日期和连续天数防重；断签后再次达到第七天可领取。
   能量签到也显示真实连签，但不会转换为现金；奖励仍按原配置和资格发放。
2. 管理员进入 `/admin/play-ops?tab=checkin`，按用户/日期查询记录、原连签、实际连签、资格、奖励流水和调整。
   勾选后预览，填写核实原因并通过二次验证，最多 50 条同事务执行；成功后刷新可回读。
   缺少历史资格或冻结规则时只提示待核实，不能推算旧日应补金额，不自动补发生产历史奖励。
3. 用户农场将今日任务、本月 Token 能量分别展示。四项 Token 为输入、输出、缓存创建、缓存读取。
   管理员在原农场 Tab 查同一用户，可看到四项实际用量、旧/新折算、今日任务与当前合计，以及独立资格成长能量。
   管理查询不会写任务进度；历史日期不套用今天的任务规则。新周期包含缓存读取；既有周期保持旧口径，需管理员预览确认切换。
4. 在农场 Tab 选择日/月周期、查看历史已到账证据；规则冻结与新周期生效明确区分。
   当前期切换需核对排名和奖励影响、填写原因、二次验证；预览过期整笔拒绝，已结束/已发奖周期不能直接改口径。
   新结算全事务提交，失败可重试，不产生部分发奖。升级前的部分发奖缺少稳定名单时阻止盲目重跑，需先核实证据。
5. 四项运维页面归入“智能运维”组合菜单，保留原 URL：优先调度、质量运维、凭证运营、鹈鹕测试。
   固定上游 `6f813426b61b8eeba77f374059205cc34d2fa993` 的 AppSidebar 确认同样使用父菜单和独立子路由。
   本次只调整这四个已有入口；上游其他子功能留待后续差异逐项处理。
